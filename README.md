## Publicar en GitHub Pages

En `camilolpgc/Viaje-a-Tfe`, rama `main`, utiliza **Add file → Upload files** y arrastra directamente el contenido de esta carpeta (no el ZIP). Deben quedar en la raíz `index.html`, `styles.css`, `script.js`, `README.md` y dentro de `assets/` ambas fotos. Confirma con **Commit changes**. Después actualiza la web con Ctrl+F5.

Los tracks GPX están integrados en `script.js`, por lo que no se necesita añadir la carpeta `routes/`.

Asegúrate de disponer de autorización para utilizar las dos fotografías facilitadas en una página pública.
