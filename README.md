# Huellas de fuego, raíces de vida · Tenerife 2027

Web de proyecto educativo para el alumnado del Felo Monzón.

## Publicación en GitHub Pages

Subir los cuatro archivos de esta carpeta a la raíz de la rama `main` (no subir el ZIP). Ir a Settings → Pages → Deploy from a branch → main / (root).

## Mapas

Las tres rutas (Viñátigos, Chanajiga–La Fortaleza y La Orotava) incorporan los datos GPX directamente dentro de `script.js`. No hace falta subir una carpeta `routes`. Los mapas base de OpenStreetMap sí requieren internet.

- Día 2: track circular aportado de 2.584 puntos; longitud aproximada calculada 18,7 km.
- Los GPX descargables desde la web se generan a partir de los datos incluidos.
- Verificar siempre condiciones, permisos y recorridos antes de la salida.

La actividad corresponde a un proyecto de clase, no a una oferta comercial abierta al público.
